# Commandes d'exécution de l'application

## Backend (Flask API)
- **Commande :** `.\venv\Scripts\python api\app.py`
- **Port :** 5000 (URL par défaut : `http://127.0.0.1:5000`)

## Frontend (React / Vite)
- **Commande :** `npm run dev` (exécutée depuis le dossier `frontend/`)
- **Port :** 5173 (URL par défaut : `http://localhost:5173`)
